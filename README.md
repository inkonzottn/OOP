## 🛠 Детальніше про проекти

### 1. 📚 Лабораторні роботи (Labas)
Збірка лабораторних робіт з курсу програмування на Java.
* Основи синтаксису.
* Об'єктно-орієнтоване програмування (ООП).
* Робота зі структурами даних.

### 2. 👥 Навчальна практика (NP) — "Команда розробників"
Командний проект, створений під час проходження навчальної практики.
* **Backend:** Java + Maven (керування залежностями).
* **Frontend:** Bootstrap (адаптивна верстка та стилізація).
* **Database:** MySQL
* **Функціонал:** Робота з інформацією про розробників, управління структурою команди.
